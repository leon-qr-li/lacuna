# Roles: site 站长 / 站点管理员 / 用户; show 管理员 / 剪辑师 / 只听; support access by the show's consent

Date: 2026-10-21. Decided by Leon (batch 3 decision pack, questions 6–8, option A each; 03:01Z).
Supersedes / changes: `invites-roles-2fa` (role names; site staff no longer see every show).

## Decision
- Site roles (ids unchanged: owner / admin / member): 站长 / Owner, 站点管理员 / Site admin, 用户 / User.
  Site admins invite and manage users and set plans; only the owner makes site admins and changes the AI
  key and mail settings.
- Show roles (ids admin / editor / viewer): 管理员 / Admin, 剪辑师 / Editor, 只听 / Listen.
  Editors import and do all editing. Only show admins invite, change show settings (`PUT /api/show`,
  `PATCH /api/albums/project`, picture), archive, or delete for good. 节目设置 is read-only for the others.
- The site owner and site admins cannot open other people's shows. A show's admins can switch on
  「允许 LACUNA 支持查看」 (节目设置 → 协作者): site staff then see that show read-only (as 只听) for
  7 days, after which it turns off by itself.

## Why
Users' recordings are private by default, also from us; support looks only when asked, read-only, for a
limited time. Show-level permissions follow how a podcast team actually works.
