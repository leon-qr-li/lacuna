# 喜马拉雅版 defaults to 「片场」, which starts at the title

Date: 2026-10-18 · Source: Leon during validation (V9)

- The 「喜马拉雅版」 tab opens on 「片场」 instead of 「杂志」; a style picked after that is remembered
  (localStorage `lacuna.ximalaya.style.v2`; the old key is ignored so a choice made while 杂志 was
  the default doesn't hide the new default, second full scan). 杂志 and 图文 stay available.
- 「片场」 no longer prints the "<episode> · 洛城二三事" line above the title; the notes start straight at the title.
