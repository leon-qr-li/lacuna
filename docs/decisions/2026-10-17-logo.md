# LACUNA Studio logo: V3「光晕」

Leon, 2026-10-17 19:58Z, after three rounds (round 1: five directions; round 2: sunset wave / hidden-LA
monogram in six colourways / Hollywood hills; round 3: six iterations of the C3 monogram).
Previews: `/mnt/project-files/lacuna/screenshots/logo/` (round2/, round3/, in_app/).

- **Mark:** one pulse line that hides "L" (stem + foot) and "A" (the peak, no crossbar) and then dips like
  a waveform; sunset gradient (gold → orange → pink → violet) on a navy rounded square; neon glow; a
  glowing red ON AIR light top right. LA without spelling it; reads as a studio / sound tool.
- **Why not literal LA letters:** Leon felt plain "LA" looked like city tourism, not studio software.
- **One source file:** `web/src/features/brand/logo.svg`. Favicon, top bar, sign-in brand panel and the
  desktop icons (`installer/LACUNA.ico`, `installer/LACUNA.icns`) all derive from it (`design/logo/`).
- **Desktop icon on existing installs:** the launcher copies the icons from the current version into the
  install root and recreates the shortcuts the first time it starts a version whose icon changed.
