# First-party event log in the site database, from now on

Date: 2026-10-21. Claude 技术决策 (from the admin-metrics recommendation Leon read 02:00Z: 「先把事件日志做起来」).
Supersedes / changes: —

## Decision
lacuna_app/events.py writes one row per meaningful action to the `events` table: `ts, uid, sid, ep, ev,
props` — sign-up, sign-in, show created, import started/finished/failed (audio length, duration, failed
step), review decisions, AI batch review, export, publish… (routes/events.py `RULES` + `track()` calls).
`uid` is the account's internal id, never the email; `props` take only numbers, booleans and short words
(no transcript text, file names, emails or addresses). Raw events are kept 13 months. Deleting an account
removes the only link from its id to the person. Nothing leaves our server; no third-party analytics.

## Why
The admin batch needs history (sign-ups, activation, retention, funnel, AI quality, cost); collecting it
starts now so those pages have data on day one.
