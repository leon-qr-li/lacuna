# A project has at most four hosts; an import at most four tracks

- Date: 2026-10-21
- Status: CONFIRMED（Leon, 2026-10-20 22:21Z）
- Supersedes / changes: —

`show.MAX_HOSTS = 4`. A fifth host is refused (server and 项目设置 → 主持人), and an import with more than
four tracks is refused before anything is uploaded or processed. A 4-host editing test with real audio stays on
the pre-launch test list.
