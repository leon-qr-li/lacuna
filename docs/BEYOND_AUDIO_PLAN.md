## 不变的约束（适用于下面每一项）

- 音频、剧照、海报底图等**用户媒体不出本机**；发给 Claude API 的只有文字和数值特征（CLAUDE.md）。
  所以 Claude 不“看”剧照、不“听”配乐：它读文件名/曲目信息、本地算出的结构数字和整集转写。
- 素材只用 Leon 自己提供的（D13）：不抓取、不下载、不录 Spotify。AI 可以说“这里想要一段什么样的音乐”，但不编造不存在的片段时间。
- AI 生成的只有**文字**（标题、简介、show notes、海报上的字）——人声永远只来自原始录音（R001 / D08）。
- 任何对外发布动作都要 Leon 亲手确认（PRD；D20）。`已导出 / 已上传 / 已发布 / 小宇宙已同步` 是四个不同状态，只有核实过才标。
- 运行费用：API 走 Max 自带额度（D23）。下面各项估算按现有单价（`editor.py` PRICES，Opus 5.5 $4 / $20 每百万 token）。

## 1. 素材库（media library）

**做什么**：一个本地素材库，Leon 只管把文件丢进文件夹，其余 App 管。
- 位置：`<workspace>/library/`，按用途分子目录：`jingles/`（系列片头/片尾）、`music/`（电影原声）、`clips/`（台词/预告片段）。
  另外每集有自己的收件箱 `<workspace>/episodes/<ep>/assets/`（Journey 1 第 5 步）。
- 自动入库：监视文件夹（防抖 + 文件大小稳定后才读，避免读到复制一半的文件）→ 内容 hash 作为稳定 ID →
  ffprobe 取格式/时长 → 本地分析：响度（LUFS）、能量曲线、段落边界、起音/收尾点、是否有人声 →
  从文件名和已有标签推出“电影 / 作曲 / 曲名”。全部写进 SQLite 索引；原文件只读、不改名不移动。
- “缺素材”任务：AI 需要某段音乐/台词但库里没有 → 建好目标文件夹、说清楚要什么，其他工作不停（Playbook）。
- UI：素材页（列表 + 试听 + 用在哪几集），不做手动打标签。

**技术**：全是本地 numpy / ffmpeg，已有的 `lacuna_core/media.py` 可复用；不需要 GPU，不需要新付费服务。

## 2. 选音乐与配乐（含片头规则、ducking）

分两步，对应 D24 的 MVP 收窄：

**2a 用户指定，App 放好（MVP）** = 路线图第 6 阶段：
- 系列片头规则：Leon 说一次“这个片头是 90 年代系列的”，记成系列规则，下一集自动提议（Playbook）。
- 聊天里说“这里放《XX》的主题曲” → 从素材库找到文件 → 放到时间线（独立音乐轨，非破坏，进 EDL）→ 可试听。
- 两种音量角色（Playbook）：过场/间奏 = 正常音量；铺底 = 很低，人声出现时自动 ducking，人声永远清楚。
- 台词片段插入：“把刚放进去的台词加在这儿，前面留半秒”。
- 导出走同一条母带链（D36），音乐总线进混音。

**2b AI 主动推荐（MVP 之后）**：
- AI 读整集转写，找出适合放音乐/台词的位置（话题切换、提到某部电影、情绪段落），说明理由。
- 库里有这部电影的原声 → 用本地结构分析（能量曲线、段落、渐强/收尾点）+ Claude 对这部电影和曲目的知识，提 2–3 个候选片段（in/out 来自真实文件的分析，不是编的）；**好不好听由 Leon 试听决定**（评估风险 2）。
- 库里没有 → 只描述想要的情绪/功能，建“缺素材”任务。
- 学习：Leon 接受/换掉/删掉推荐，进第 5 阶段的学习模块（D27）。
- 费用：每集一次，约 $0.2–0.4（整集转写约 4 万 token 输入）。

## 3. 发布资料包（标题、简介、show notes、章节）

**做什么**：导出成品后，一键生成“发布资料”，Leon 改改就能用。
- 内容（PRD “Outputs”）：3–5 个标题候选、一句话简介、show notes（聊了哪些电影/人物、要点、提到的片名中英文）、
  章节时间戳（按**成品时间线**，不是原始录音时间）、上传清单。
- 做法：整集转写（按当前剪辑后的时间线）+ 话题切分 → Claude 写文字。章节时间由本地从片段 ID 换算，模型不写时间（同 D37 的思路：模型只引用编号）。
- 片名/人名纠错：ASR 对片名、英文名容易错（评估风险），show notes 里的专有名词单独列出，让 Leon 一眼核对；改过的写进词表，下一集 ASR 和 show notes 都受益。
- 风格：Leon 给 2–3 集过去的 show notes → 作为风格样例放进提示；之后他的修改进学习模块。
- 输出：App 里一个“发布”页，每段文字有“复制”按钮；同时存成 `<workspace>/exports/<ep>/publish/notes.md`。
- 费用：每集一次约 $0.2–0.3；重新生成某一段（比如只换标题）几分钱。

## 4. 海报（封面）

Claude API **不生成图片**，本机 GTX 1660S 6GB 跑本地生图模型很慢、画不出中文字（HARDWARE_PROFILE）。所以推荐：

**模板排版（推荐，本地、免费）**：
- 节目自己的版式模板（栏目 logo、配色、字体、系列标识），一次设计好、每集套用。
- 底图 = Leon 提供的剧照/官方海报（放进本集收件箱）；文字 = 发布资料包里选定的标题 + 片名 + 期数。
- Claude 只写文字、从几个模板变体里选一个（依据是文字，不看图片）。
- 本地用已经装好的 Chromium 把 HTML 模板渲染成 PNG，出平台要求的尺寸（喜马拉雅/小宇宙封面都是正方形，另出一张横版备用）。
- Leon 在 App 里改字、换底图、选变体，实时预览。

**备选**（需要 Leon 决定，见文末问题）：付费生图 API 生成底图（每张几毛到几块钱，但把“海报风格”交给外部服务）；
或本地生图（免费但慢、质量一般）。两种都只生成底图，字仍由模板排。

## 5. 发布（喜马拉雅 + 小宇宙）

**现状核实（2026-10-17）**：
- 喜马拉雅开放平台的公开文档面向“把喜马拉雅内容接入 App/硬件”（内容查询、播放、OAuth 登录），
  没找到面向个人主播的“上传声音”接口说明，个人账号能否申请仍是**未证实**（D20 不变）。
- 喜马拉雅创作中心可以生成 RSS（“创作实验室 → Apple 播客托管服务”），小宇宙等平台可以用 RSS 导入并自动更新。
  Leon 现在的 小宇宙 是不是这样同步的，要问他（文末问题）。

**分三档，逐档做**：
1. **辅助发布（先做）**：发布页集中放好 WAV 文件位置（一键打开文件夹）、标题/简介/show notes/章节（一键复制）、
   海报 PNG、一个“打开喜马拉雅上传页”按钮，和一张勾选清单。Leon 自己上传、自己点发布。零风险。
2. **浏览器代填（之后试）**：用 Playwright 打开 Leon **自己登录过**的浏览器配置，自动填好标题、简介、上传音频和封面，
   停在“发布”按钮前，由 Leon 亲手点。先在一集上验证稳不稳、平台允不允许；不稳就退回第 1 档。
   登录信息只留在 Leon 电脑上，App 不保存密码。
3. **状态核实**：发布后 App 读公开 RSS / 节目页（只读）确认“已发布”“小宇宙已同步”，没核实到就不标。

不做：无人值守的自动发布；绕过平台规则的批量操作。

- 第 7 阶段（打包更新）、第 8 阶段（UI 审美）不受影响；发布页和素材页的视觉放进第 8 阶段一起打磨。
